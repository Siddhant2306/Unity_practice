# Unity_practice — Anomaly / Horror (Unity)

A Unity project built as an **anomaly-style horror game**: you explore scenes and look for “something off” (anomalies), with a simple menu + gameplay scene setup.

> Unity version (from `ProjectSettings/ProjectVersion.txt`): **6000.0.58f1**

## What’s inside

- `Assets/MainMenu.unity` — main menu scene.
- `Assets/horror_game_scene2.unity` — gameplay scene.
- `Assets/Scripts/` — gameplay & UI scripts.
- `Assets/Audios/`, `Assets/Videos/`, `Assets/Shaders/` — media + rendering assets.

## Getting started

### 1) Open in Unity

1. Install **Unity 6000.0.58f1** (Unity Hub → Installs).
2. Unity Hub → **Add** → select this project folder (`Unity_practice/`).
3. Open the project.

### 2) Play

- Open `MainMenu` scene and press **Play**.
- From the menu, start the game (loads the horror/anomaly scene).

## Notes

- Unity-generated folders like `Library/` can be large; they’re typically not committed in clean Unity repos. If you’re cloning fresh, Unity will regenerate them.
- If you see missing materials/textures on first open, let Unity finish importing assets; then re-open the target scene.
